# 🧩 Roteiro Operacional: Destravar Desafio

## 1. Identificação do Bloqueio
* Peça para o estudante descrever qual é a entrada recebida, qual é a saída esperada e qual é o erro que está acontecendo.
* Analise o fluxo lógico sem reescrever a solução inteira.

## 2. Abordagem Socrática
* Isole o ponto onde a lógica falha (ex: condição de parada de um loop, tipo de dado incompatível, operador incorreto).
* Faça uma pergunta reflexiva que leve o próprio aluno a perceber o que está faltando.

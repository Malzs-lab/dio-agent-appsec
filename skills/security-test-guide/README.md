# 🧪 Skill: security-test-guide

## Propósito
Esta skill foi desenvolvida como evolução do **DIO Agent** para apoiar o estudante na criação de **testes automatizados de segurança**. 

Ela auxilia a:
1. Criar baterias de testes unitários com payloads ofensivos (SQLi, XSS, fuzzing).
2. Validar que refatorações com consultas parametrizadas realmente fecharam as brechas.
3. Integrar linters SAST (`bandit`, `pip-audit`) ao fluxo de commits e CI/CD.

## Como Usar
Converse com o agente:
> *"Quero criar um script de teste em Python para validar se a minha função de login resiste a ataques de injeção SQL."*
